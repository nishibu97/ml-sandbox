# 4. ディープラーニングの研究分野

## 4-1 | 一般物体認識とその応用

### 画像認識タスクの全体整理

| タスク | 出力 | 代表モデル |
|---|---|---|
| **画像分類 (Classification)** | 画像全体に1ラベル | VGG, ResNet |
| **物体検出 (Object Detection)** | 矩形(BBox)＋クラス | R-CNN系, YOLO, SSD |
| **セマンティック・セグメンテーション** | 画素ごとクラス(同一クラス物体は区別しない) | FCN, U-Net, SegNet |
| **インスタンス・セグメンテーション** | 画素ごとクラス＋個体ID | Mask R-CNN, YOLACT |
| **パノプティック・セグメンテーション (Panoptic Segmentation)** | セマンティック+インスタンスの統合 | Panoptic FPN |
| **姿勢推定 (Pose Estimation)** | 関節キーポイント | OpenPose |
| **OCR (Optical Character Recognition)** | 画像中の文字をテキスト化 | Tesseract, CRNN |

### 物体検出
- **物体検出 (Object Detection)**：バウンディングボックス(矩形)を用いて物体の候補領域を切り出した後に、候補領域を画像分類器に入力してクラスを推定する。代表例はR-CNN、Fast R-CNN、Faster R-CNN、SSD、YOLOなど
- **Selective Search**：R-CNNで物体の候補領域を見つけるのに用いる手法。色や強度などが類似する隣接ピクセルをグルーピングする
- **RPN (Region Proposal Network)**：Faster R-CNNで導入された、候補領域を生成する小さなニューラルネット。Selective Search を置き換えることで高速化を実現
- **Anchor Box**：あらかじめ定めた複数の縦横比・スケールの基準矩形。物体検出モデルが各位置に対し基準矩形を当てはめてオフセットを学習する
- **IoU (Intersection over Union)**：予測矩形と正解矩形の重なり度合い。重なり面積 ÷ 和集合面積。物体検出の精度評価や NMS の閾値判定に用いる
- **mAP (mean Average Precision)**：クラスごとに計算した AP の平均値。物体検出の主要評価指標
- **NMS (Non-Maximum Suppression, 非最大値抑制)**：重複する検出矩形のうちスコア最大のもの以外を IoU 閾値で抑制する後処理
- **Two-Stage 検出器**：候補領域生成→分類の2段階方式。R-CNN系。精度高めだが遅い
- **One-Stage 検出器**：候補領域生成と分類を1ネットで同時実行。YOLO、SSD。高速だが精度はやや劣る傾向
- **YOLO (You Only Look Once)**：画像をグリッドに分割し各グリッドで矩形と確率を一括予測する One-Stage 検出器。v1(2016)から継続的に発展(v2/v3/v4/v5/v7/v8 等)。リアルタイム性に強み

### セグメンテーション
- **セマンティック・セグメンテーション (Semantic Segmentation)**：物体の輪郭を画素単位で精密に切り出し、各画素にクラスを割り当てる一般物体認識の手法。同一クラスの個体は区別しない。代表的なモデルはFCN、U-Net、SegNet、DeepLab、PSPNetなど
- **FCN (Fully Convolutional Network ; 完全畳み込みネットワーク)**：全ての層が畳み込み層から成り立つ、セマンティック・セグメンテーションのモデル。画素ごとにラベル付けした教師データで学習させ、未知の画像に対し、画素ごとにカテゴリを予測する
- **U-Net**：エンコーダ・デコーダ構造に**スキップ接続**を加えた U字型モデル。医療画像セグメンテーションで有名
- **SegNet**：セマンティック・セグメンテーションのモデル。エンコーダを用いて入力画像から特徴マップを抽出し、デコーダを用いて特徴マップと元の画像の画素位置の対応関係をマッピングする。メモリ効率がFCNより高い
- **DeepLab**：Atrous Convolution(膨張畳み込み)を用いて受容野を拡大するセマンティック・セグメンテーションモデル
- **PSPNet (Pyramid Scene Parsing Network)**：複数スケールの特徴を統合する Pyramid Pooling を導入
- **インスタンス・セグメンテーション (Instance Segmentation)**：物体検出とセマンティック・セグメンテーションを統合した手法。重なった物体や同一クラスに属する物体の境界・形状の判別が強み。代表的なモデルはYOLACTやMask R-CNNなど
- **Mask R-CNN**：Faster R-CNN を拡張し、各候補領域に対し画素単位マスクを出力する分岐を追加したインスタンス・セグメンテーションモデル
- **パノプティック・セグメンテーション (Panoptic Segmentation)**：セマンティック・セグメンテーションとインスタンス・セグメンテーションを統合し、すべての画素に「クラス＋個体ID(該当時)」を付与する

### その他
- **OpenPose**：CMU が開発した姿勢推定モデル。人物の関節点(キーポイント)を検出し骨格を描く
- **OCR (Optical Character Recognition ; 光学文字認識)**：画像中の文字をテキストに変換する技術
- **ニューラル画像脚注付け (Neural Image Captioning, NIC)**：ニューラルネットワークの技術を活用し、画像に写っている物体の説明を自動生成する技術。エンコーダ部分のCNNで画像に写っている物体を検出・認識し、デコーダ部分のRNNで画像認識の結果を描写する自然言語テキストを生成する

## 4-2 | 自然言語処理

### 前処理・古典的手法
- **コーパス (Corpus)**：自然言語処理のために用いられる大規模なテキストデータ
- **形態素解析 (Morphological Analysis)**：言語解析の初期段階で行う処理の1つ。文章を単語や文節で区切ることで「意味を持つ表現要素の最小単位」(形態素)に分割し、さらに各要素の品詞を推定する。代表ツール：MeCab、Janome、Sudachi
- **構文解析 (Syntactic Parsing)**：文の文法構造(主語・述語・修飾関係)を解析する処理
- **BoW (Bag of Words)**：文書を単語の出現頻度ベクトルで表現する素朴な手法。語順を無視
- **n-gram**：連続する n 個の単語(または文字)の並び。文脈の局所性を表現
- **TF-IDF (Term Frequency - Inverse Document Frequency)**：文章中の単語の重要度を定量化する手法。値が大きいほど単語の重要度が高いと推定される。単語の文章内での出現頻度TFとその単語が存在する文章の割合の逆数の対数IDFの積として計算される

### 単語の分散表現
- **分散表現 (Distributed Representation)**：単語を低次元の密なベクトルで表現する手法。意味的類似度をベクトル距離で扱える
- **Word2Vec (2013, Mikolov)**：単語の分散表現を学習するニューラルネットモデル。**CBOW**(周辺語から中心語を予測)と**Skip-gram**(中心語から周辺語を予測)の2方式。「king - man + woman ≈ queen」のような線形演算で類推可能
- **GloVe (Global Vectors)**：単語共起行列の統計に基づく分散表現手法。スタンフォード大が提案
- **fastText**：Facebook が開発。サブワード(文字 n-gram)を活用し、未知語にも頑健
- **ELMo (Embeddings from Language Models)**：双方向LSTMで文脈依存の単語ベクトルを得る手法。Word2Vecと違い同じ単語でも文脈で表現が変わる

### トークナイザ(サブワード分割)
- **BPE (Byte Pair Encoding)**：頻出文字列ペアを段階的にマージしてサブワード語彙を構築する手法。GPT系で使用
- **WordPiece**：Google が BERT で採用するサブワード分割手法
- **SentencePiece**：Google が公開した言語非依存のサブワード分割ツール

### Encoder-Decoder と Attention
- **seq2seq (Sequence-to-Sequence)**：入力系列を出力系列に変換するEncoder-Decoder型モデル。機械翻訳で広く使用
- **従来のEncoder-Decoderモデル**：入力文全体を1個の固定長ベクトルに圧縮してからデコーダに渡す。次の時刻の状態を計算できるものの「過去のある時刻の情報の重要性」を計算できない。翻訳前の文章が長いと翻訳精度が悪化
- **Attention機構**：過去の各時刻の情報(翻訳前の単語)に重みを付与した上でデコーダの出力に反映させる。長い文章でも高精度に翻訳可能

### Transformer ★★
> 派生モデル(ViT, Swin)・スケーリング則・LLM の詳細は [9-生成AI・基盤モデル特集](9-生成AI・基盤モデル特集.md) 参照。本節は要点ダイジェスト。

- **Transformer (2017, Vaswani et al. "Attention is All You Need")**：RNN や CNN を使わず、Self-Attention のみで系列を処理するモデル。並列計算が容易で長距離依存に強い。現代の NLP・生成AI の基盤。系列長 N に対し計算量は O(N²)
- **Self-Attention (自己注意)**：入力系列中の各要素が、同じ系列内の全要素との関連度(Attention重み)を計算し、重み付き平均で表現を更新する仕組み
- **Multi-Head Attention**：Self-Attention を複数の「頭(head)」で並列実行し、異なる観点の関係を同時に学習
- **Positional Encoding (位置エンコーディング)**：Transformer は語順情報を持たないため、位置情報を sin/cos などで埋め込みベクトルに加算
- **Encoder-only / Decoder-only / Encoder-Decoder**：Transformer の3系統。**Encoder-only=BERT系**(理解タスク向け)、**Decoder-only=GPT系**(生成タスク向け)、**Encoder-Decoder=T5/BART系**(変換タスク向け)

### 事前学習モデル
- **事前学習モデル (Pre-trained Model)**：大規模なコーパスを用い教師なし学習(自己教師あり学習)を行い、汎用的な特徴を学習し終えている学習済みモデル。ファインチューニングを通じて個別のタスクに利用する
- **スケール則 (Scaling Laws)**：モデルのサイズ(パラメータ数)・データ量・計算量が増加するにつれて、モデルの性能もほぼべき乗則に従って向上するという経験則(2020, OpenAI)
- **BERT (Bidirectional Encoder Representations from Transformers)**：2018年にGoogleが提案した事前学習モデル。エンコーダーにTransformerを活用し、「過去→現在」と「未来→現在」の双方向の情報を使用できる。事前学習のためにMasked Language Model(MLM)とNext Sentence Prediction(NSP)を実行する。パラメータ数はBERT-baseが約1.1億、BERT-largeが約3.4億。2019年に軽量版であるALBERTやDistilBERTが公開された
- **MT-DNN**：Microsoft社が開発した事前学習モデル。ロジックはBERTも参考にしている
- **GPT (Generative Pre-trained Transformer)**：OpenAIが開発した、デコーダにTransformerを用いた事前学習モデル。過去の単語列から次の単語を予測するように学習を行い、自然な文章を生成可能。初代GPTはパラメータ数が1.1億、GPT-2は15億、GPT-3は1750億、GPT-4は非公開
- **T5 (Text-to-Text Transfer Transformer)**：Google が公開。あらゆるNLPタスクを「テキスト→テキスト」変換に統一したEncoder-Decoder型事前学習モデル
- **BART**：Facebook が公開。Encoder-Decoder型でノイズ除去型の事前学習を行うモデル。要約に強い
- **LLaMA (Large Language Model Meta AI)**：Meta が公開した大規模言語モデル。研究用途で広く利用される。LLaMA 2、LLaMA 3 と発展
- **PaLM / PaLM 2 / Gemini**：Google の大規模言語モデル系列

### 推論時の学習パラダイム
- **Zero-shot Learning**：例示なしでタスクを実行
- **One-shot Learning**：例を1個だけ与えて実行
- **Few-shot Learning**：数個の例(プロンプト中の例示)だけでタスクを実行。文章の書き出しを与えるだけで続きを自動生成できる
- **In-Context Learning (文脈内学習)**：プロンプト内の例示から推論時にタスクを学ぶ仕組み。パラメータは更新しない
- **CoT (Chain-of-Thought, 思考の連鎖)**：「ステップごとに考えて」と促すことで、推論過程を明示的に生成させ精度を高めるプロンプト手法
- **Instruction Tuning (指示チューニング)**：「指示文＋応答」形式のデータでファインチューニングし、指示追従能力を高める手法

### 評価指標
| 指標 | 用途 |
|---|---|
| **BLEU** | 機械翻訳の品質(n-gram 一致率ベース) |
| **ROUGE** | 要約の品質(再現率ベース) |
| **METEOR** | 翻訳の品質(同義語・語幹を考慮) |
| **Perplexity (パープレキシティ)** | 言語モデルの「次単語予測の難しさ」。低いほど良い |

## 4-3 | 音声認識・音声生成

### 音声信号の処理
- **A-D変換 (Analog-to-Digital Conversion)**：時間に対し連続的に変化するアナログデータをコンピュータで処理可能な離散的なデジタル(数値)データに変換する手法。以下が変換の流れ
    - ①標本化(サンプリング)：連続的な音波を一定の時間間隔ごとに切り出す
    - ②量子化：波の強さを離散的な値に近似する
    - ③符号化：量子化された値をビット列で表現する
- **サンプリング定理 (標本化定理 ; Nyquist Theorem)**：「A-D変換で、デジタル化後のデータから元のアナログ信号の波形を正確に再現するには、元の信号に含まれる最も高い周波数の2倍を超えるサンプリング周波数で標本化をすればよい」ということを示した定理
- **高速フーリエ変換 (FFT, Fast Fourier Transform)**：複数の周波数成分の重なりである時間ごとの音声信号を、周波数スペクトルに高速に変換する手法

### 音響特徴
- 音の基本属性である強さ、高さ、音色(音質)のうち、言語を認識する上で一番重要なのは**音色**であり、音響モデルで使用される特徴量の1つでもある
- **音素 (Phoneme)**：ある言語において意味を区別する最小の音の単位。言語ごとに体系が異なる
- **音韻**：言語に依存せず人の発声を区別できる音の要素(物理的な音の特徴)。音素より広義
  ⚠ 注意：音素＝言語依存・意味区別／音韻＝言語非依存・物理特徴。混同注意
- **スペクトル包絡 (Spectral Envelope)**：音を区別するために計算する周波数スペクトルの大まかな形状。よく用いられる手法はメル周波数ケプストラム係数。入力音声のスペクトル包絡に相当する係数列が音響モデルの特徴量となる
- **MFCC (Mel-Frequency Cepstral Coefficients ; メル周波数ケプストラム係数)**：人間の聴覚特性(メル尺度)に基づきスペクトル包絡を表現する音響特徴量。古典的 ASR の標準特徴
- **フォルマント周波数 (Formant Frequency)**：スペクトル包絡上の複数の周波数のピークで、音色の違いをもたらす。音韻が近ければフォルマント周波数も近い

### 音声認識 (ASR : Automatic Speech Recognition)
- **ASR の3要素**：**音響モデル**(音→音素確率)、**言語モデル**(単語列の自然さ)、**発音辞書**(単語と音素列の対応)。古典的 ASR はこの3つを組み合わせる
- **隠れマルコフモデル (HMM, Hidden Markov Model)**：音声処理のための統計学に基づいた確率モデル。辞書を使って音素列と単語をマッチングする
- **GMM-HMM**：従来の音響モデル。混合ガウスモデル(GMM)で音響特徴をモデル化し HMM で時系列を表現
- **DNN-HMM ハイブリッド**：GMM部分を DNN に置き換えた音響モデル。深層学習による初期の改良
- **CTC (Connectionist Temporal Classification)**：入出力系列のアライメント不要で系列ラベリングを学習できる損失関数。End-to-End ASR で使用
- **End-to-End ASR**：音響モデル・言語モデル・発音辞書を1つのニューラルネットに統合する手法。**DeepSpeech**(Baidu, CTCベース)、**RNN-T (RNN Transducer)**、**Whisper**(OpenAI 2022, 多言語・多タスク対応)など
- **SWITCHBOARD**：音声認識で使われる、音声とテキストを組み合わせたコーパス

### 音声生成 (TTS : Text-to-Speech)
- **text-to-speech (TTS)**：文章から自然な音声に変換すること。波形接続TTSとパラメトリックTTSの2種類が使われてきた
- **波形接続TTS (Concatenative TTS)**：話者による短い音節の集合体から必要なものを結合して音声を合成する。声を変えること、抑揚や感情を加えることが難しい傾向にある
- **パラメトリックTTS (Parametric TTS)**：文章から音声に変換するtext-to-speech(TTS)手法の1つ。話す内容や特徴(口の動き、声の高さや抑揚など)を入力パラメータによって操作しながら音声を生成。音を連結する必要がないので、波形接続TTSよりも処理が高速であるが、生成された音声の自然さ(人間らしさ)が波形接続TTSに劣る
- **WaveNet (ウェーブネット)**：2016年にDeepMind社により発表された音声処理モデル。既存手法よりも自然な音声を高速に生成できる。音声系列の1つ1つの点をCNNを用いて生成。Dilation Causal ConvolutionをCNNに取り入れることで長時間の依存関係に対応可能
- **Tacotron / Tacotron 2**：Google が開発した DNN ベース TTS。テキストからメルスペクトログラムを生成し、Vocoder で波形化する2段構成
- **Vocoder (ボコーダ)**：メルスペクトログラム等の音響特徴量から音声波形を生成するモジュール。代表例：WaveNet、WaveGlow、HiFi-GAN
- **VC (Voice Conversion ; 声質変換)**：話者の声質を別の話者の声質に変換する技術

## 4-4 | 生成AIの仕組みと応用

### GAN (敵対的生成ネットワーク)
- **敵対的生成ネットワーク (Generative Adversarial Networks ; GAN, 2014, Goodfellow)**：2種のネットワーク、ジェネレータ(生成器)とディスクリミネータ(識別器)を競合させることで、本物と見分けられないような新しい画像サンプルを生成する深層生成モデル
- **ディープフェイク (Deepfake)**：GANを用いて実在しない対象物の新たな画像を合成する技術。社会問題化(後述 6章)
- **DCGAN (Deep Convolutional GAN)**：ジェネレータとディスクリミネータの両方にCNNを採用したGANの強化版
- **CGAN (Conditional GAN)**：クラスラベル等の条件を与えて生成する GAN
- **StyleGAN**：NVIDIA が開発。スタイルベクトルで生成画像を制御でき、高解像度の人物顔画像生成で有名
- **BigGAN**：Google が大規模化した GAN。ImageNet の高品質生成
- **Pix2Pix**：教師あり学習を使い、変換前の画像(入力画像)と変換後の画像(目標画像)のピクセルの対応関係を直接的に学習するスタイル変換モデル
- **CycleGAN**：教師なし学習を用いて「変換前後のデータセット同士の分野や領域の関係」を習得することで画像変換を実現する。ペア画像不要
- **モード崩壊 (Mode Collapse)**：GAN の主要課題。ジェネレータが多様性を失い、特定パターンの画像しか生成しなくなる現象

### VAE
- **VAE (変分オートエンコーダ ; Variational Auto-Encoder)**：オートエンコーダを活用した深層生成モデル。入力画像の特徴量を統計分布(平均と分散)に変換し、そこからデータ点をランダムサンプリングし、デコーダによって復元することで新しい画像データを生成する

### 拡散モデル (Diffusion Model) ★★
> Classifier-Free Guidance や派生モデル比較は [9-生成AI・基盤モデル特集](9-生成AI・基盤モデル特集.md) 参照。本節は要点ダイジェスト。

- **拡散モデル (Diffusion Model)**：データに段階的にノイズを加える「順過程」と、ノイズを段階的に除去する「逆過程」を学習する深層生成モデル。GAN を上回る生成品質と訓練安定性で、現在の画像生成主流
- **DDPM (Denoising Diffusion Probabilistic Model, 2020)**：拡散モデルの代表的定式化
- **LDM (Latent Diffusion Model)**：画像をオートエンコーダで潜在空間に圧縮し、そこで拡散過程を行う高速化手法。Stable Diffusion の基盤
- **Stable Diffusion (2022, Stability AI)**：LDM ベースのオープンソース画像生成モデル。テキストから画像生成
- **GLIDE (OpenAI)**：拡散モデルに条件付き誘導(Classifier-Free Guidance)を取り入れた画像生成モデル
- **DALL・E 2 (OpenAI)**：画像認識モデルのCLIPと、画像を生成する拡散モデルおよび条件付ける誘導拡散を取り入れたGLIDEで構成された画像生成モデル
- **DALL・E 3 (OpenAI)**：DALL・E 2 の後継。プロンプト忠実度が大幅向上
- **Imagen (Google)**：Google の拡散モデルベースの画像生成モデル
- **Midjourney**：拡散モデルベースの商用画像生成サービス。芸術性の高い画像で人気
- **Sora (OpenAI, 2024)**：拡散モデルベースの動画生成モデル
- **Veo (Google)**：Google の動画生成モデル

### マルチモーダル(画像×言語)
- **CLIP (Contrastive Language-Image Pre-training, 2021, OpenAI)**：画像とテキストの対比学習で対応関係を学んだマルチモーダル基盤モデル。Zero-shot画像分類や、DALL・E 2・Stable Diffusion などの画像生成モデルの条件付け部に利用される
- **VLM (Vision-Language Model)**：画像と言語を統合的に扱うモデルの総称。GPT-4V、Gemini、Flamingo など

### 評価指標
- **FID (Fréchet Inception Distance)**：生成画像と実画像の Inception 特徴量分布の距離。低いほど良い
- **IS (Inception Score)**：生成画像の品質と多様性を測る指標。高いほど良い

### 文章生成 AI 関連
- **幻覚 (ハルシネーション ; Hallucination)**：文章生成AIが学習データにはない内容を質問された時など、一番確率が高い答えを返した結果、事実とは異なる内容となってしまうこと
- **Reinforcement Learning from Human Feedback (RLHF)**：人間が手を加えて作成したデータと人間によるフィードバックを使用して、GPTモデルのファインチューニング(パラメータの微調整)を行い、ChatGPTの機能を仕上げる手法。多様な質問や表現に対して、自然で正確な応答を生成可能になり、捏造や差別的な表現も減少。「教師あり学習」「報酬モデルの学習」「強化学習(PPO)」のステップで構成される

## 4-5 | 深層強化学習・ロボティクスへの応用

### 基礎
- **深層強化学習 (Deep Reinforcement Learning)**：ディープラーニングを強化学習に取り入れた手法。ディープラーニングを用いて行動価値や方策を推定し、状態を表現しやすくなり学習効率が向上した
- **MDP (Markov Decision Process ; マルコフ決定過程)**：強化学習の数学的基礎。「状態・行動・遷移確率・報酬・割引率」で定式化される枠組み
- **報酬シェーピング (Reward Shaping)**：エージェントが学習しやすいように補助的な報酬を設計する手法
- **スパース報酬 (Sparse Reward)**：報酬がまれにしか得られない設定。学習困難につながる課題
- **OpenAI Gym**：強化学習の環境をシミュレーションで構築するツール

### アルゴリズムの分類

| 観点 | 種類 | 説明 |
|---|---|---|
| 何を学習するか | **価値ベース** | 行動価値関数を推定し、間接的に方策を最適化(Q学習、DQN) |
|  | **方策ベース** | 数理モデルで直接的に方策のよさを推定(REINFORCE) |
|  | **Actor-Critic** | 方策と価値を同時に学習(A3C, A2C, PPO) |
| 環境を学ぶか | **モデルベース** | 環境をパラメータで明示的に表現し、最適化(MuZero) |
|  | **モデルフリー** | 環境パラメータを推定せずに方策を求める(Q学習等) |
| 経験の使い方 | **On-policy** | 現在の方策で集めた経験で更新(SARSA, A2C, PPO) |
|  | **Off-policy** | 過去の方策の経験も再利用(Q学習, DQN, DDPG, SAC) |

### 価値ベース
- **Q学習 (Q-Learning)**：ある状態の時にとったある行動のQ値(行動価値関数)を、Qテーブルという形式で管理し、行動を実行するたびにQ値を更新する手法。Off-policy
- **SARSA**：「今選択した行動によって、価値の高い状態に遷移できるか」を評価するために、実際にエージェントを行動させて得られた状態を伝播させ、これを参考にQ値(状態行動価値)を更新し行動を最適化する強化学習のアルゴリズム。On-policy
- **DQN (Deep Q-Network)**：深層強化学習の代表的なアルゴリズムで、Q学習において、ニューラルネットワークを用いた近似関数を通じて、ある状態の時にある行動をとる場合のQ値を推定し、「最もよいQ値になる行動 = 取るべき最適な行動」を探索する仕組み
- **ε-greedy法**：行動探索の範囲を狭めないように、常にQ値が最大となる行動ではなく、一定の確率εでランダムな行動を取り入れる手法
- **ターゲットネットワーク (Target Network)**：現在学習中のネットワークと、過去に遡ったネットワークのTD誤差を教師データのように使う。価値の推定を安定させる効果がある
- **経験再生 (Experience Replay)**：環境を探索中に得られる経験データをリプレイバッファーに保存し、そこから適切なタイミングでランダムに抜き出して学習に利用することで、学習を安定化させる効果を発揮する

#### DQN の拡張
- **Double DQN (ダブルDQN)**：行動選択用と価値推定用に別ネットを使い、Q値の過大評価を抑制
- **Dueling Network (デュエリングネットワーク)**：状態価値関数 V(s) と行動アドバンテージ A(s,a) に分解して学習
- **Noisy Network (ノイジーネットワーク)**：ネットワーク重みにノイズを加え、ε-greedyに代わる探索を実現
- **RAINBOW**：DQNの拡張版である、ダブルDQN、デュエリングネットワーク、ノイジーネットワーク、優先度付き経験再生、Distributional DQN、Multi-step Learning などの特徴を組み合わせた「全部載せ」モデル

### 方策ベース・Actor-Critic
- **方策勾配法 (Policy Gradient)**：方策の良さを直接最適化する手法群
- **REINFORCE**：方策勾配法の代表的アルゴリズム。1エピソードの収益で勾配を推定
- **Actor-Critic**：方策に従って行動を選択するActor(行動器)を直接改善しながら、状態価値関数に応じて方策を評価・修正するCritic(評価器)を同時に学習させる手法
- **A3C (Asynchronous Advantage Actor-Critic)**：複数のエージェントが同じ環境で非同期に学習することを特徴とする、Actor-Criticを用いたアルゴリズム。DeepMind社が提案
- **A2C (Advantage Actor-Critic)**：A3C の同期版。実装が簡潔で広く使用される
- **PPO (Proximal Policy Optimization)**：方策更新幅を制限することで安定した学習を実現する現代的方策勾配法。ChatGPT の RLHF でも使用される代表手法
- **TRPO (Trust Region Policy Optimization)**：信頼領域内でのみ方策を更新する手法。PPO の前身
- **DDPG (Deep Deterministic Policy Gradient)**：連続行動空間向けの Off-policy Actor-Critic
- **SAC (Soft Actor-Critic)**：エントロピー最大化を取り入れた連続行動空間向け Off-policy 手法

### sim2real とロボティクス
- **sim2real**：シミュレーションを用いて方策を学習した後に、実世界の環境に適用する手法。シミュレーションの環境に過学習することが課題
- **ドメインランダマイゼーション (Domain Randomization ; 環境乱択化)**：シミュレーション環境を実世界の環境に近づけるために環境パラメータをランダムに変更させ、多様な環境で性能を発揮するモデルを訓練することを目指す
- **オフライン強化学習 (Offline RL)**：シミュレーションのデータを学習や性能評価に用いず、実環境から集めた過去のデータのみを使って行う強化学習
- **オンライン強化学習 (Online RL)**：実際に環境と作用しながら行う強化学習
- **逆強化学習 (Inverse Reinforcement Learning)**：エキスパートの行動データから、その行動を最適とするような報酬関数を推定する手法
- **模倣学習 (Imitation Learning)**：エキスパートの行動を直接模倣して方策を学ぶ手法

### 代表的な応用事例
- **AlphaGo**：DeepMind社が開発した、DQNをベースとした囲碁AI。2016年に李世乭(イ・セドル)九段を破る
- **AlphaGo Zero**：AlphaGoの改良版。人間の対戦データを必要とせず、完全自己対局で学習することが特徴
- **AlphaZero**：囲碁に限らず、将棋やチェスなどの分野でも活躍する汎化版
- **AlphaStar**：DeepMind が開発した StarCraft II の AI。プロプレイヤーレベルに到達
- **AlphaFold (2020/2024)**：DeepMind が開発したタンパク質構造予測 AI。2024年にノーベル化学賞を受賞(Hassabis、Jumper)
- **MuZero**：環境モデルを学習しながら計画を行うモデルベース手法。AlphaZero を発展

## 4-6 | モデルの説明と解釈

### 解釈の粒度

| 粒度 | 説明 | 代表手法 |
|---|---|---|
| **大局的説明 (Global)** | モデル全体としての予測傾向を解釈 | Permutation Importance、PDP、ALE |
| **局所的説明 (Local)** | 個別の予測の根拠を解釈 | Grad-CAM、LIME、SHAP、Counterfactual |

### 主要手法
- **Grad-CAM (Gradient-weighted Class Activation Mapping)**：CNNを対象とする**局所的**なモデル解釈ツール。個別の入力画像に対し、最終畳み込み層の勾配の情報を用いて予測根拠をヒートマップで可視化する。勾配が大きい画素は予測に大きく影響すると判断して重みをつける
- **LIME (Local Interpretable Model-agnostic Explanations)**：局所的なモデル解釈ツール。特定の入力データに対する予測の根拠を解釈する。入力周辺で線形モデル等の単純モデルを当てはめて説明
- **SHAP (SHapley Additive exPlanations)**：協力ゲーム理論のシャープレイ値に基づき、各特徴量の寄与を公平に分配して説明する手法。局所説明・大局説明の双方に使える(詳細は 6章)
- **Permutation Importance (順列重要度)**：特徴量をシャッフルして精度低下度合いを測ることで重要度を算出する大局説明手法
- **Counterfactual Explanation (反実仮想説明)**：「予測結果を変えるには入力をどう変えればよいか」を示す局所説明手法

## 4-7 | マルチモーダル AI と基盤モデル
> LLM・基盤モデルの3段階学習(SFT→RLHF/DPO)、PEFT(LoRA等)、RAG、エージェント、評価ベンチマークは [9-生成AI・基盤モデル特集](9-生成AI・基盤モデル特集.md) 参照。本節は要点ダイジェスト。

- **マルチモーダルAI (Multimodal AI)**：画像、音声、テキストなど複数タイプの入力情報を同時に利用するAI
- **基盤モデル (Foundation Model)**：大規模データで事前学習された汎用モデル。多様な下流タスクにファインチューニング/プロンプトで適応可能(2021、Stanford HAI が提唱)
- **CLIP**：4-4 参照。画像とテキストの対比学習で得られたマルチモーダル基盤モデル
- **Flamingo (DeepMind)**：画像と文章を交互に処理できる Few-shot 対応の VLM
- **GPT-4V (Vision)**：OpenAI の GPT-4 に画像入力機能を追加したマルチモーダルモデル
- **Gemini (Google)**：テキスト・画像・音声・動画を統合的に扱えるマルチモーダル基盤モデル
- **VLM (Vision-Language Model)**：画像と言語を統合的に扱うモデルの総称

## 4-8 | グラフニューラルネットワーク (GNN)
- **GNN (Graph Neural Network)**：ノードとエッジから構成されるグラフ構造データを扱うニューラルネットワーク。各ノードが近傍ノードの情報を集約・更新することで表現を学習
- **GCN (Graph Convolutional Network)**：畳み込みをグラフに拡張した GNN の代表手法
- **応用例**：分子設計(薬剤候補探索)、推薦システム、SNS 分析、交通流予測、知識グラフ補完など

- **PyTorch**：ディープラーニング実装のためのオープンソースのフレームワーク。Meta(旧Facebook)が開発。研究分野で広く採用
- **TensorFlow / Keras**：Google が開発したディープラーニングフレームワーク
- **JAX**：Google が開発した自動微分・XLA コンパイル対応の数値計算ライブラリ
