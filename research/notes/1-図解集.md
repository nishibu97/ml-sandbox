## 1-2 意味ネットワーク

#### 意味ネットワーク（is-a / part-of の階層）

```mermaid
graph BT
    Sparrow[スズメ<br/>下位概念]
    Penguin[ペンギン]
    Bird[鳥<br/>概念]
    Animal[動物<br/>上位概念]
    Wing[羽]
    Beak[くちばし]

    Car[自動車]
    Vehicle[乗り物]
    Tire[タイヤ]
    Engine[エンジン]

    Sparrow ==>|is-a| Bird
    Penguin ==>|is-a| Bird
    Bird ==>|is-a| Animal
    Wing -.->|part-of| Bird
    Beak -.->|part-of| Bird

    Car ==>|is-a| Vehicle
    Tire -.->|part-of| Car
    Engine -.->|part-of| Car

    style Bird fill:#cfe
    style Car fill:#cfe
```

> 太い実線（==>）が **is-a**（〜の一種）、点線（-.->）が **part-of**（〜の一部）。

## 1-5 AIによる情報処理の仕組み

#### 探索木の基本構造

```mermaid
graph TD
    Root((ルート<br/>初期状態))
    Root --> N1((子1))

    N2 --> N21((孫))
    N3 --> N31((孫))
    N3 --> N32((孫))
    N31 --> Goal((ゴール))

    style Root fill:#cfe
    style Goal fill:#fce
```

#### 幅優先探索の訪問順（横方向に層ごと）

```mermaid
graph TD
    A((①)) --> B((②))
    A --> C((③))
    A --> D((④))
    B --> E((⑤))
    B --> F((⑥))
    C --> G((⑦))
    D --> H((⑧))
    D --> I((⑨))

    style A fill:#cfe
    style B fill:#cfe
    style C fill:#cfe
    style D fill:#cfe
```

> 番号順 = 訪問順。**同じ深さを全部調べてから次の深さへ**。最短経路を必ず発見、メモリ大。

#### 深さ優先探索の訪問順（縦方向に深く）

```mermaid
graph TD
    A((①)) --> B((②))
    A --> G((⑦))
    B --> C((③))
    B --> D((④))
    C --> Z1((※行き止まり<br/>戻る))
    D --> E((⑤))
    D --> F((⑥))
    G --> H((⑧))
    G --> I((⑨))

    style A fill:#cfe
    style B fill:#cfe
    style C fill:#cfe
    style D fill:#cfe
```

> 番号順 = 訪問順。**ある枝を行き止まりまで掘り進め**、戻って別枝へ（バックトラック）。メモリ小、最短保証なし。

#### 幅優先 vs 深さ優先の特性比較

```mermaid
graph LR
    BFS[幅優先探索<br/>BFS]
    DFS[深さ優先探索<br/>DFS]

    BFS --> BFS1[キュー<br/>FIFO]
    BFS --> BFS2[最短経路○]
    BFS --> BFS3[メモリ消費 大]
    BFS --> BFS4[浅い解に強い]

    DFS --> DFS1[スタック<br/>LIFO]
    DFS --> DFS2[最短経路×]
    DFS --> DFS3[メモリ消費 小]
    DFS --> DFS4[深い解に強い]

    style BFS fill:#cfe
    style DFS fill:#fce
```
