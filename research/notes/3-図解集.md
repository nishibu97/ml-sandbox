## 3-1 ニューラルネットワークの学習の基本

#### ニューロンの計算モデル

```mermaid
graph LR
    X1[入力 x1] -->|重み w1| Sum
    X2[入力 x2] -->|重み w2| Sum
    X3[入力 x3] -->|重み w3| Sum
    Bias[バイアス b] --> Sum
    Sum[線形和<br/>Σwᵢxᵢ + b] --> Act[活性化関数<br/>例: ReLU]
    Act --> Y[出力 y]

    style Sum fill:#cfe
    style Act fill:#fce
    style Y fill:#fec
```

#### 単純パーセプトロン vs 多層パーセプトロン

```mermaid
graph LR
    subgraph SP [単純パーセプトロン]
        SI[入力層] --> SO[出力層]
    end
    subgraph MLP [多層パーセプトロン MLP]
        MI[入力層] --> MH1[隠れ層 1]
        MH1 --> MH2[隠れ層 2]
        MH2 --> MO[出力層]
    end

    SP -. 解けない .-> XOR[XOR問題<br/>線形分離不可]
    MLP -. 解ける .-> NL[非線形問題]

    style SP fill:#fcc
    style MLP fill:#cfe
    style XOR fill:#fcc
    style NL fill:#cfe
```

#### 活性化関数の比較

```mermaid
graph TD
    Act[活性化関数]
    Act --> Sig[シグモイド<br/>0〜1]
    Act --> Tanh[tanh<br/>-1〜1]
    Act --> ReLU[ReLU<br/>0以下は0、それ以外そのまま]
    Act --> Leaky[Leaky ReLU<br/>負側にもわずかな傾き]
    Act --> Soft[ソフトマックス<br/>合計1の確率]
    Act --> Iden[恒等関数<br/>そのまま出力]

    Sig -. 用途 .-> SigU[2値分類の出力層]
    ReLU -. 用途 .-> ReLUU[隠れ層の標準]
    Soft -. 用途 .-> SoftU[多クラス分類の出力層]
    Iden -. 用途 .-> IdenU[回帰の出力層]

    Sig -. 問題 .-> SigP[勾配消失]
    ReLU -. 問題 .-> ReLUP[死んだReLU]

    style ReLU fill:#cfe
    style Soft fill:#fce
    style Sig fill:#fec
```

#### 誤差逆伝播法（Backpropagation）

```mermaid
graph LR
    Input[入力] -->|順伝播| H1[隠れ層1]
    H1 -->|順伝播| H2[隠れ層2]
    H2 -->|順伝播| Out[出力]
    Out --> Loss[損失計算<br/>予測 vs 正解]

    Loss -.->|逆伝播 勾配| H2g[H2の勾配]
    H2g -.->|逆伝播| H1g[H1の勾配]
    H1g -.->|重み更新| Update[各層の重みを更新]

    style Loss fill:#fce
    style Update fill:#cfe
```

#### 重み初期化の使い分け

```mermaid
graph TD

    Init --> Xavier[Xavier / Glorot]

    Xavier -. 適 .-> XAct[シグモイド・tanh]
```

## 3-2 ニューラルネットワークの学習における工夫

```mermaid

    Saddle -. 特徴 .-> S1[ある方向は谷<br/>別方向は山]
```

## 3-3 リカレントニューラルネットワーク (RNN)

#### RNN の時間展開

```mermaid
graph LR
    X0[x_0] --> H0[h_0]
    H0 --> Y0[y_0]
    H0 -->|フィードバック| H1[h_1]
    X1[x_1] --> H1
    H1 --> Y1[y_1]
    H1 -->|フィードバック| H2[h_2]
    X2[x_2] --> H2
    H2 --> Y2[y_2]
    H2 -->|…| HN[h_t]

    style H0 fill:#cfe
    style H1 fill:#cfe
    style H2 fill:#cfe
```

> 過去の隠れ状態 hₜ₋₁ を次の時刻に持ち越す。学習は **BPTT**（時間方向の誤差逆伝播）。

#### LSTM の内部構造

```mermaid
graph LR
    In[入力 x_t]
    Prev[前時刻 h_t-1]

    In --> ForG[忘却ゲート<br/>Forget Gate]
    Prev --> ForG
    In --> InG[入力ゲート<br/>Input Gate]
    Prev --> InG
    In --> OutG[出力ゲート<br/>Output Gate]
    Prev --> OutG

    ForG -->|過去の記憶を<br/>どれだけ忘れるか| CEC[CEC<br/>Constant Error Carousel<br/>長期記憶]
    InG -->|新情報を<br/>どれだけ書き込むか| CEC
    CEC --> OutG2[出力ゲートで<br/>どれだけ出すか]
    OutG --> OutG2
    OutG2 --> Out[出力 h_t]

    style CEC fill:#cfe
    style ForG fill:#fce
    style InG fill:#fce
    style OutG fill:#fce
```

#### LSTM vs GRU

```mermaid
graph TD
    LSTM[LSTM<br/>3ゲート + CEC]
    GRU[GRU<br/>2ゲート / CEC無]

    LSTM --> L1[入力ゲート]
    LSTM --> L2[忘却ゲート]
    LSTM --> L3[出力ゲート]
    LSTM --> L4[CEC<br/>長期記憶]

    GRU --> G1[更新ゲート<br/>Update Gate]
    GRU --> G2[リセットゲート<br/>Reset Gate]

    LSTM -. 特徴 .-> LF[表現力高 / 計算重い]
    GRU -. 特徴 .-> GF[シンプル / 高速]

    style LSTM fill:#cfe
    style GRU fill:#fce
```

#### 双方向RNN の構造

```mermaid
graph LR
    X1[x_1] --> Fwd1[順方向 RNN]
    X2[x_2] --> Fwd2[順方向 RNN]
    X3[x_3] --> Fwd3[順方向 RNN]
    Fwd1 --> Fwd2 --> Fwd3

    X1 --> Bwd1[逆方向 RNN]
    X2 --> Bwd2[逆方向 RNN]
    X3 --> Bwd3[逆方向 RNN]
    Bwd3 --> Bwd2 --> Bwd1

    Fwd1 --> Y1[y_1]
    Bwd1 --> Y1
    Fwd2 --> Y2[y_2]
    Bwd2 --> Y2

    style Fwd1 fill:#cfe

```

#### seq2seq の構造

```mermaid
graph LR
    subgraph Enc [エンコーダ]
        E1[RNN] --> E2[RNN] --> E3[RNN]
    end
    Ctx[文脈ベクトル<br/>Context Vector]
    subgraph Dec [デコーダ]
        D1[RNN] --> D2[RNN] --> D3[RNN]

    In1[Hello] --> E1
    In2[World] --> E2

    E3 --> Ctx

```

#### Attention 機構の概念

```mermaid
graph LR
    DecH[デコーダの<br/>現在の隠れ状態]
    EncH1[エンコーダ h_1]
    EncH2[エンコーダ h_2]
    EncH3[エンコーダ h_3]
    EncH4[エンコーダ h_4]

    DecH -->|類似度 注意重み α| EncH1
    DecH -->|α| EncH2
    DecH -->|α| EncH3
    DecH -->|α| EncH4

    EncH1 -->|α₁倍| Sum[重み付き和]
    EncH2 -->|α₂倍| Sum
    EncH3 -->|α₃倍| Sum
    EncH4 -->|α₄倍| Sum

    Sum --> Out[文脈ベクトル<br/>各時刻ごとに動的生成]

    style DecH fill:#fce
    style Sum fill:#cfe
    style Out fill:#fec
```

> 各デコーダ時刻でエンコーダ全位置を参照、重要な位置を**重み α** で強調。Transformer の中核。
