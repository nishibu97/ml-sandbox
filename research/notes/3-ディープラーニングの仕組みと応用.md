# 3-1. ニューラルネットワークの学習の基本
- 単純パーセプトロン: 入力層と出力層の2層だけで構成される初期のネットワーク。線形分離可能な簡単な問題しか解けず、XOR問題が解けないという限界があった。
- 多層パーセプトロン: 入力層と出力層の間に「隠れ層（中間層）」を追加した3層以上のネットワーク。これにより複雑な非線形の問題が解けるようになった。
- 勾配消失問題: ネットワークの層を深くしていくと、誤差を逆伝播する際の「勾配（重みの修正量）」が入力層に近づくにつれてゼロになってしまい、学習が進まなくなる深刻な問題。
- 誤差逆伝播法 (Backpropagation): 出力層で計算した予測と正解の誤差を、入力層に向かって逆向き（後ろから前へ）に伝達し、各層のパラメータ（重み）を効率的に更新する学習の基本アルゴリズム。
- 活性化関数: ニューロンに入力された信号の合計を、次へどのように出力するかを決定する関数。ネットワークに「非線形性（複雑さ）」を持たせるための要。
- 特徴量: 予測の手がかりとなるデータの特徴。機械学習では人間が設計していたが、ディープラーニングではAIが自ら特徴量を抽出できるようになった。
- ニューロン: 人間の脳の神経細胞を模した数理モデルの単位。入力値に重みを掛け、バイアスを足して活性化関数を通すという計算を行う。
- シグモイド関数: 出力値を「0から1の間」に滑らかに収める活性化関数。層が深くなると勾配消失問題を引き起こす主な原因となるため、現在は隠れ層ではあまり使われない。
- Tanh関数（ハイパーボリックタンジェント関数）: 出力値を「-1から1の間」に収める活性化関数。シグモイド関数よりは勾配消失が起きにくいが、完全な解決策ではない。
- ReLU関数（Rectified Linear Unit function）: 入力が0以下の場合は「0」、0より大きければ「そのまま」出力する活性化関数。計算が軽く、勾配消失問題を防ぐ効果が高いため、現在の隠れ層で最も標準的に使われる。
- 死んだReLU問題（Dying ReLU）: ReLU は入力が負の領域では出力も勾配も常に0になるため、一度活性化されなくなったニューロンが二度と学習に寄与しなくなる問題。
- Leaky ReLU: 死んだReLU問題への対策。負の入力に対しても**わずかな傾き（例：0.01x）**を持たせ、勾配がゼロにならないようにした活性化関数。
- ELU / GELU / Swish: ReLUの発展型。**GELU**は Transformer（BERT、GPT）の標準活性化関数。**Swish**は Google が提案した滑らかな ReLU 系。
- ソフトマックス関数: 複数の出力値の合計が「1（100%）」になるように確率に変換する関数。主に画像分類などの「多クラス分類」における出力層で使われる。
- 恒等関数（Identity Function）: 入力をそのまま出力する関数。**回帰タスクの出力層**で使われる（連続値をそのまま出すため）。
- 損失関数: モデルの予測値と、実際の正解値との「ズレ（誤差）」を計算する関数。AIの学習とは、この損失関数の値を最小化する作業のことである。
    - **平均二乗誤差（MSE）**: 回帰タスクの標準損失。
    - **クロスエントロピー誤差**: 分類タスクの標準損失。ソフトマックスとセットで使う。

### 重み初期化
- 重み初期化（Initialization）: ニューラルネットの学習開始時の重みの値を決める処理。初期値が不適切だと**勾配消失・爆発**を引き起こす。**ゼロ初期化はNG**（全ニューロンが同じ更新になる）。
- Xavier初期化（Glorot初期化）: 活性化関数が**シグモイド・tanh** のときに適する初期化方法。前層と次層のノード数を考慮した分散で初期化する。
- He初期化（Kaiming初期化）: 活性化関数が **ReLU 系**のときに適する初期化方法。Xavier の改良版で、現在の隠れ層の標準。

# 3-2. ニューラルネットワークの学習における工夫

- 勾配降下法(Gradient Descent): 損失関数の値を最小にするために、山の斜面を下るようにパラメータ（重み）を少しずつ更新していく最適化の手法。
    - 大域最適解　局所最適解問題: 本当の谷底（大域最適解）に行きたいのに、途中の小さなくぼみ（局所最適解）にハマって学習が止まってしまう問題。
- プラトー: 損失関数の勾配（傾き）が平坦になってしまい、重みの更新が進まず学習が停滞してしまう「平原」のような状態。
- 鞍点 (サドルポイント): ある方向からは極小値（谷）だが、別の方向からは極大値（山）に見える馬の鞍のようなポイント。学習が停滞する原因の一つ。
- 学習率: 1回の学習で重みをどれくらい大きく更新するか（斜面を下る歩幅）を決める重要なハイパーパラメータ。大きすぎると発散し、小さすぎると学習が終わらない。
- 学習率スケジューリング: 学習の進行に合わせて学習率を変化させる手法。代表例：
    - **学習率減衰（Learning Rate Decay）**: 学習が進むにつれ徐々に学習率を下げる。
    - **Warmup**: 学習初期は学習率を小さく、徐々に上げる手法。Transformer 等で標準。
    - **Cosine Annealing**: コサインカーブで滑らかに学習率を変化させる。
- イテレーション: 学習データをミニバッチに分割した際、重みを更新した「回数」のこと。
- エポック: 用意した学習データセット全体を「何周」学習したかを表す単位。
- 確率的勾配降下法（SGD, Stochastic Gradient Descent）: データをランダムに1件ずつ取り出して学習・更新を行う手法。計算が速く局所最適解から抜け出しやすい。
- ミニバッチ学習: データを数件〜数十件の小さな束（バッチ）に分割し、その束ごとに誤差の平均をとって重みを更新する、現在主流の学習手法。
- バッチサイズ: ミニバッチ学習において、1つの束に入れるデータの数のこと。ハイパーパラメータとして人間が設定する。
- オンライン学習: データが手に入るたびに、リアルタイムで少しずつモデルを学習・更新していくアプローチ。
- バッチ学習(最急降下法): 用意した全データを一気に計算して、重みを1回だけ更新する手法。メモリ消費が激しく局所最適解に陥りやすい。
- 早期終了（Early Stopping）: 過学習を防ぐため、検証データでの精度が向上しなくなった（誤差が下がらなくなった）時点で、予定のエポック数に達していなくても学習を打ち切る手法。
- 強化学習: （※ここはリストに含まれていますが、最適化手法ではなくAIの学習分野の一つです）報酬を最大化する行動を学習するアプローチ。
- モメンタム（Momentum）: 過去の勾配を「慣性」として加味し、SGD の更新方向を滑らかにする最適化手法。プラトーや鞍点を抜け出しやすくなる。Adam の構成要素の一つ。
- 勾配降下法のアルゴリズム (AdaGrad, RMSprop, Adam): 学習率を手動で決めるのではなく、学習の進行度合いに合わせて自動で最適に調整してくれるアルゴリズム。現在は**Adam（アダム）**が最もよく使われる。
    - **AdaGrad**: パラメータごとに学習率を調整するが、学習率が単調減少してしまう欠点がある。
    - **RMSprop**: AdaGrad の減衰問題を改善。指数移動平均で過去の勾配を扱う。
    - **Adam**: モメンタム + RMSprop の良いとこどり。実務の標準。
    - **AdamW**: Adam に正しい重み減衰（Weight Decay）を組み合わせた改良版。Transformer の学習で標準。
- 勾配クリッピング（Gradient Clipping）: 勾配の大きさが閾値を超えたらスケーリングして抑える手法。**勾配爆発**の対策、特に RNN/LSTM の学習で重要。
- データ拡張 (Data Augmentation): 画像を回転させたり、反転・色調変更などで水増しし、擬似的に学習データ量を増やして過学習を防ぐアプローチ。
    - **Mixup**: 2枚の画像とラベルを線形に混ぜて新しいサンプルを作る手法。
    - **CutMix**: ある画像の一部を切り出して別画像に貼り付け、ラベルも面積比でブレンドする手法。
    - **RandAugment**: 複数のデータ拡張をランダムに組み合わせる自動化手法。
- 転移学習: ある目的で学習済みのモデルの重みを初期値として使い、出力層だけを付け替えて別のタスク用に学習し直す手法。少ないデータでも高精度が出やすい。
- ファインチューニング: 転移学習と似ているが、出力層だけでなく「ネットワーク全体の重み」も新しいタスクに合わせて微調整（再学習）する手法。
- バッチ正規化 (Batch Normalization, BN): 各層を流れるデータを、**ミニバッチごと**に正規化（平均0、分散1）する処理。学習が非常に安定し、速度が飛躍的に向上する。CNN で標準。
- レイヤー正規化 (Layer Normalization, LN): 各サンプルの**特徴量方向**で正規化する手法。ミニバッチサイズに依存しないため、**RNN や Transformer で標準**として採用されている。
- インスタンス正規化 / グループ正規化: BN の派生。**Instance Normalization** はサンプル×チャネル単位（スタイル変換に有効）、**Group Normalization** はチャネルをグループ化して正規化（小バッチに有利）。
- 内部共変量シフト: ネットワークの層を通過するごとに、データ分布のバランスが崩れてしまう現象。バッチ正規化はこれを防ぐために考案された。
- ドロップアウト: 学習時に隠れ層のニューロンをランダムに無効化（無視）しながら学習する手法。特定のニューロンへの過剰な依存を防ぎ、過学習を強力に抑える。**アンサンブル学習に近い効果**を持つ。
- モデルを軽量化する手段
    - プルーニング（枝刈り）: 予測への影響が小さい不要な重み（ニューロンの繋がり）を削除して、モデルの計算量とサイズを減らす手法。
    - 蒸留 (Knowledge Distillation): 巨大で高性能なモデル（教師）の予測結果を、軽量なモデル（生徒）に模倣させて学習させ、性能を引き継がせる手法。
    - 量子化 (Quantization): パラメータの数値を表現するビット数（例：32bitの小数を8bitの整数など）を減らし、メモリ使用量と推論速度を向上させる手法。

# 3-3. リカレントニューラルネットワーク(RNN)

- RNN (リカレントネットワークとは): 音声や文章などの時系列データを処理するため、過去の隠れ層の情報を記憶として引き継ぐ「フィードバック機構」を持つネットワーク。
- フィードバック機構: 中間層の出力の一部を、次の時刻の自身の層の入力として再度ループさせる構造のこと。
- 時系列データ: 時間の経過とともに記録されたデータ。音声、動画、自然言語（文章の単語の並び）、株価など、前後の順番に意味があるデータ。
- BPTT（Back Propagation Through Time）: RNNを時間方向に展開し、過去にさかのぼって誤差逆伝播を行う、RNN専用の学習アルゴリズム。
- 勾配消失問題（RNN）: RNN は時間方向に深いネットワークになるため、長い系列では勾配が極小化し、**長期依存（Long-term dependency）**の学習が困難になる。
- 勾配爆発問題（Exploding Gradient）: RNN で逆に勾配が指数的に増大し学習が発散する問題。**勾配クリッピング**で対処。
- 重み衝突問題: RNN において、過去の情報を記憶し続ける重みと、新しい入力に対する重みが衝突し、長期的な記憶の学習が困難になる問題（LSTM論文で言及）。
- LSTM（Long Short Term Memory）: RNN の勾配消失問題と長期依存問題を解決し、**長期的な記憶を保持**できるようにした高度な RNN モデル。Google翻訳などで大活躍した。
- CEC（Constant Error Carousel）: LSTMの中核。勾配消失を防ぎながら、過去の記憶（誤差）をそのまま長期間保持するための専用の記憶装置（小部屋）。
- LSTMにおいて、活性化関数を用いて情報の取捨選択を行うゲート構造には、入力ゲート、出力ゲート、忘却ゲートの3種類がある
    - 入力ゲート: 新しい入力データのうち、どれだけをCEC（記憶）に保存するかを判断する門。
    - 出力ゲート: CECの記憶のうち、どれだけを次の層への出力として利用するかを判断する門。
    - 忘却ゲート: CECの過去の記憶のうち、不要になったものをどれだけ「忘れる（消去する）」かを判断する門。
- GRU: LSTMの構造を簡略化し、計算コストを軽くしたRNNモデル。CECを持たず、「リセットゲート」と「更新ゲート」の2つの門だけで記憶を制御する。
- 双方向RNN（Bidirectional RNN, BiRNN / BiLSTM）: 時系列を**前から後ろへ読むRNN**と**後ろから前へ読むRNN**を組み合わせた構造。文中の単語を周囲の文脈から理解する用途（固有表現抽出、機械翻訳のエンコーダ等）で有効。
- seq2seq（Sequence-to-Sequence）: 入力系列を**エンコーダ**で固定長ベクトルに圧縮し、**デコーダ**で出力系列を生成するモデル。機械翻訳・対話・要約に使われる。代表例：Google翻訳のRNNベース時代（2014, Sutskever）。
- Attention 機構（注意機構）★: seq2seq の弱点（長文では情報が圧縮しきれない）を解決した手法。デコーダの各時刻で、エンコーダの**全ての位置の中から関連が深いもの**を重み付きで参照する。**Transformer の中核となる革新技術**（4章で詳述）。

# 3-4. 畳み込みニューラルネットワーク(CNN)と画像認識

- 畳み込みニューラルネットワークとは: 人間の視覚野の働きを模し、画像の特徴を効率的に抽出する、画像認識で圧倒的な精度を誇るモデルアーキテクチャ。
- 画像認識とは: AIに画像を入力し、それが「何であるか（分類）」や「どこにあるか（検出）」を判定させるタスク全般のこと。
- 畳み込み層、プーリング層、全結合層の三種類のレイヤーから構成される: CNNの基本構造。特徴を抽出し、ズレを吸収し、最後に分類を行う。
- 畳み込み層: 画像の特徴抽出を行う層。画像にフィルタという小さな画像を重ね、スライドさせながら畳み込み演算（積和演算）を行う。
    - 特徴マップが生成される: 畳み込み演算の結果として出力される、画像の輪郭（エッジ）などの特徴が強調されたデータのこと。
    - ストライドとは: フィルタをスライドさせる際の「移動するピクセル幅（歩幅）」のこと。
    - 計算方法の例: フィルタ内の数値と、重なる画像の画素値を掛け合わせ、すべての合計を出す計算。
    - **チャネル**: 入力画像のRGB等の色成分や、各層の特徴マップの枚数のこと。
    - **受容野（Receptive Field）**: 出力の1点が、入力画像のどの範囲を「見ている」かを表す領域。層が深いほど広くなる。
- 1×1畳み込み（Pointwise Convolution）: フィルタサイズが 1×1 の畳み込み。**チャネル方向の次元削減**に使われる。GoogLeNet のインセプションモジュールや ResNet のボトルネック構造で活用。
- プーリング層: 特徴マップの解像度を下げて情報を圧縮（ダウンサンプリング）し、画像が少しズレていても同じように認識できる頑健性（**位置不変性**）を持たせる層。
    - **Maxプーリング（Max Pooling）**: 領域内の**最大値**を取る。最も標準的。輪郭などの強い特徴を保持。
    - **平均プーリング（Average Pooling）**: 領域内の**平均値**を取る。滑らかな特徴を保持。
- Global Average Pooling（GAP）: 各特徴マップ全体の平均値を1つに集約する手法。**全結合層を置き換えてパラメータ数を大幅削減**できる。GoogLeNet・ResNet 以降で標準。
- パディング: 畳み込みを行う前に、画像の周囲をダミーデータ（主に0）で囲む処理。画像の端の情報が失われたり、画像サイズが小さくなりすぎるのを防ぐ。
    - **ゼロパディング**: 0 で埋める標準手法。
    - **Sameパディング / Validパディング**: 出力サイズを入力と同じにする / パディングなしで縮める方式。
- ILSVRC: 2010年〜2017年に開催された画像認識の大規模な世界大会。エラー率（誤差率）の低さを競い、ディープラーニングの進化を牽引した。
- ImageNet: ILSVRCで使用された、1400万枚以上の画像に手作業でラベル付けされた巨大な画像データセット。
    - WordNet: 概念の階層構造（上位・下位など）を持った英単語辞書。ImageNetのラベルはこのWordNetのオントロジーに従って整理されている。
- CNNの代表モデル
    - **LeNet**（1998, Yann LeCun）: CNN の元祖。手書き数字認識（MNIST）に適用された7層のシンプルなCNN。GoogLeNet の名前の由来でもある。
    - **AlexNet**（2012）: ILSVRC で初めて優勝した CNN モデル。ReLU 関数やドロップアウトを採用し、**第3次AIブームの火付け役**となった歴史的モデル。8層。
    - **VGG（VGG16/VGG19）**（2014）: ILSVRC 2位。**3×3 の小さな畳み込みのみを多数積み重ねる**シンプルな構造。理解しやすく転移学習でも頻用される。
    - **GoogLeNet**（2014）: ILSVRC で優勝した CNN モデル。**「インセプションモジュール」**という、異なるサイズのフィルタを**並列で適用**する複雑な構造を持つ。1×1 畳み込みで次元削減を行う点がポイント。22層。
    - **ResNet**（2015）: ILSVRC で優勝した CNN モデル。**152層**という超深層化を実現し、初めて人間の認識精度を超えた歴史的モデル。
        - **スキップ結合（残差結合, Skip Connection / Residual Connection）**: ある層の入力を、いくつ先の層の出力に「ショートカットして足し合わせる」構造。超深層でも勾配消失が起きにくくなる。
    - **DenseNet**（2017）: 各層が**過去すべての層**と直接つながる構造。特徴の再利用とパラメータ削減を実現。
    - **MobileNet**（2017）: モバイル端末向けの軽量 CNN。**Depthwise Separable Convolution**（深さ方向と点方向に分離した畳み込み）でパラメータを削減。
    - **EfficientNet**（2019）: ネットワークの「深さ」「広さ（チャネル数）」「解像度」を、**Compound Coefficient（複合係数）**を用いてバランス良く同時に拡大し、高効率・高精度を実現したモデル。
    - **Vision Transformer（ViT）**（2020）: CNN ではなく **Transformer ベース**で画像分類を行うモデル。画像をパッチに分割し、トークン列として処理する（4章で詳述）。

# 3-5. 深層強化学習

- 深層学習とは: （再掲）ニューラルネットワークを多層にし、AI自身が特徴量を抽出できるようにした機械学習の手法。
- 強化学習: エージェントが環境の中で試行錯誤し、得られる「報酬」を最大化するような最適な行動方針（方策）を学習する手法。
- エージェント: 強化学習において、環境を観測して実際に行動を起こすAIの主体（プレイヤー）のこと。
- Q値: 「ある状態のときに、ある行動をとったら、将来どれくらいの報酬がもらえそうか」を表す価値の指標（行動価値関数）。
- Q学習（Q-Learning）: 強化学習の代表アルゴリズム。**Q値（行動価値関数）**を**ベルマン方程式**に基づき、Q(s,a) ← Q(s,a) + α[r + γ·max Q(s',a') − Q(s,a)] のように繰り返し更新する。**方策オフ型（Off-policy）**。
- DQN(Deep Q-Network): **DeepMind 社**によって開発された深層強化学習の代表的な手法（2013/2015）。Q値の計算にディープラーニング（CNN）を用い、Atari のブロック崩しなどで人間超えを達成した。
    - **Double DQN**: Q値の過大評価を抑える改良版。
    - **Dueling DQN**: 状態価値 V(s) とアドバンテージ A(s,a) を分けて学習する改良版。
    - **Rainbow**: DQN の改良技法を**6種類組み合わせた総合改良版**（Double DQN、Dueling、Prioritized Experience Replay、NoisyNet、Distributional RL、N-step Learning）。
- 方策勾配法（Policy Gradient）: Q値ではなく**方策（行動の確率分布）そのものをパラメータ化**して、累積報酬の勾配で直接最適化する手法。**価値ベース**（Q学習・DQN系）と対をなす**方策ベース**のアプローチ。連続的な行動空間にも適用しやすい。
    - **REINFORCE**: 方策勾配法の最も基本的なアルゴリズム。
- アクタークリティック（Actor-Critic）: 方策（**Actor**）と価値関数（**Critic**）を同時に学習するハイブリッド手法。
    - **A3C / A2C**（Asynchronous / Synchronous Advantage Actor-Critic）: 並列に複数エージェントが学習する高速化手法。
    - **PPO（Proximal Policy Optimization）**★: OpenAI が提案した実用標準。学習の安定性が高く、**ChatGPT等の RLHF**でも採用されている。
    - **TRPO（Trust Region Policy Optimization）**: PPO の前身、信頼領域内で方策を更新する。
    - **DDPG / SAC**: 連続行動空間向けの代表手法。
- 深層強化学習有名なAI
    - **AlphaGo**（2016）: 囲碁のトップ棋士イ・セドルに勝利した AI。盤面の評価にディープラーニングを用い、手の探索に**モンテカルロ木探索（MCTS）**を採用した。
    - **AlphaGo Zero**（2017）: 人間の過去の対局データ（棋譜）を一切使わず、AI同士の**完全自己対局（self-play）**のみで学習し、AlphaGo を凌駕したAI。
    - **AlphaZero**（2017）: AlphaGo Zero の汎用版。**囲碁・将棋・チェス**を同一アーキテクチャで習得。
    - **AlphaStar**（2019, DeepMind）: リアルタイム戦略ゲーム **StarCraft II** でグランドマスター級到達。
    - **AlphaFold / AlphaFold2**（DeepMind, Hassabis & Jumper）: タンパク質の立体構造を予測。**2024年ノーベル化学賞**受賞。
    - **OpenAI Five**: Dota 2 で世界王者に勝利。
- greedy法 (貪欲法): 常にその時の状態における価値関数（Q値）が最大となるような行動のみを採用し続けるアプローチ。未知のより良い選択肢を見逃すリスクがある。
- ε -greedy法: 探索可能な行動範囲を広げるために、基本は最善手を打つが、一定の確率（ε：イプシロン）で「あえてランダムな行動（探索）」を取らせるアプローチ。
- 探索と利用のジレンマ: **探索（Exploration）**＝新しい行動を試す、**利用（Exploitation）**＝既知の最良行動を選ぶ、のバランス。多腕バンディット問題が最小モデル。
- SARSA: 強化学習のアルゴリズムの一つ。「状態・行動・報酬・次の状態・次の行動」のセットを使って Q値を更新していく**方策オン型（On-policy）**の手法。Q学習とよく比較される。
- 報酬成形（Reward Shaping）: 学習を効率化するため、報酬関数に補助的な項を加えてエージェントを誘導する手法。
- 割引率（γ, Discount Factor）: 将来の報酬を現在価値に割り引く係数（0〜1）。1 に近いほど長期報酬重視、0 に近いほど即時報酬重視。
- Mini-Max法（ミニマックス法）: 「自分にとっての最善手は、相手にとっての最悪手である」という考えに基づいた探索アルゴリズム。チェスやオセロなどのボードゲームAIの基礎。
- ブルートフォース法: 可能なすべてのパターンや手口をしらみつぶしに計算する「総当たり」アルゴリズム。
- モンテカルロ法: ランダムな乱数を大量に発生させたシミュレーションを繰り返し、近似的な解を求める数学的手法。
- マルコフ性: 「未来の状態は、現在の状態のみによって決まり、過去の履歴には一切依存しない」という性質。
    - マルコフ決定過程（Markov Decision Process）: マルコフ性を満たす環境において、エージェントが行動し報酬を得るプロセスを確率論的にモデル化したもの。
- ノイジーネットワーク (NoisyNet): ε-greedy法に代わり、ネットワークのパラメータ（重み）自体にノイズ（乱数）を加えることで、より効率的にAIに探索行動を促す手法。
- Experience Replay（経験再生）: DQNで使われる工夫。エージェントの過去の経験をメモリに貯め、そこからランダムに取り出して再学習することで、時間の連続性による偏りをなくす手法。

# 3-6. オートエンコーダとその応用

- オートエンコーダ (自己符号化器, Autoencoder): 入力データと同じものを出力するように学習させる「教師なし学習」のニューラルネットワーク。**2006年 Hinton ら**が事前学習に用いて DL ブームを再起動させた歴史的アーキテクチャ。主にデータの次元圧縮やノイズ除去に利用される。
- エンコード: 入力データを、ニューロン数の少ない隠れ層（**潜在変数, Latent Variable**）に変換し、データの特徴を抽出（圧縮）するプロセス。
- デコード: エンコードで圧縮された特徴量から、元のデータを復元（再構築）するプロセス。
- 事前学習（Pre-training）: 深いネットワークを学習させる際、勾配消失問題を防ぐため、事前にオートエンコーダを使って下位の層から順番に重みを初期化学習しておく手法。Hinton（2006）が提案。
- 積層オートエンコーダ（Stacked Autoencoder）: オートエンコーダを何層にも深く積み重ねたネットワーク構造。事前学習のアプローチとして使われた。
- ノイズ除去オートエンコーダ（Denoising Autoencoder, DAE）: 入力に**意図的にノイズを加え**、ノイズなしの元データを復元するように学習させる手法。よりロバストな特徴を獲得できる。
- スパースオートエンコーダ（Sparse Autoencoder）: 隠れ層の活性化に**スパース性（多くのニューロンが非活性）**を課す制約を入れたAE。少数の重要特徴に集中させる。
- VAE（変分オートエンコーダ, Variational Autoencoder）★: 潜在変数を**確率分布（多くは正規分布）**として扱う生成モデル（Kingma & Welling, 2014）。**ELBO（Evidence Lower Bound）**を最大化し、**再パラメータ化トリック**で勾配を流す。GAN と並ぶ生成モデルの代表（詳細は9章）。
- ボルツマンマシン（Boltzmann Machine）: 確率的な双方向結合をもつニューラルネット。Hopfield ネットの確率版。
- 制限ボルツマンマシン（RBM, Restricted Boltzmann Machine）: 可視層と隠れ層の間のみに結合を持つ単純化版。**Hinton が事前学習に活用**した。
- DBN（Deep Belief Network, 深層信念ネットワーク）: RBM を積み重ねたネットワーク。**Hinton（2006）が DL ブームの起点**として発表した代表的モデル。

# その他の重要用語

### ハードウェア・基盤
- CPU（Central Processing Unit: 中央演算処理装置）: コンピュータのメインの頭脳。複雑な条件分岐は得意だが、ディープラーニングのような単純な並列計算は GPU に劣る。
- GPU（Graphics Processing Unit）: 元々は画像描画用のプロセッサ。**多数のコアによる並列計算が得意**で、行列演算が中心のディープラーニング学習で必須の装置。**NVIDIA**が業界標準。
- GPGPU（General Purpose Computing on GPU）: 本来は画像処理用だった GPU の圧倒的な並列計算能力を、ディープラーニングなどの一般的な計算処理に転用する技術。
- TPU（Tensor Processing Unit）★: **Google が開発**したディープラーニング専用プロセッサ（ASIC の一種）。**行列演算（テンソル演算）に特化**し、GPU よりさらに高速・高効率。Google Cloud で提供。
- FPGA（Field-Programmable Gate Array）: 用途に応じて回路構成を書き換え可能な集積回路。エッジAIや組込み用途で活用される。
- ASIC（Application-Specific Integrated Circuit）: 特定用途向けに設計された集積回路。TPU は ASIC の代表例。汎用性は低いが特定処理で最高性能。
- CUDA: **NVIDIA** が提供する GPU での汎用並列計算プラットフォーム / プログラミングモデル。深層学習フレームワークの土台。

### 主要フレームワーク
- TensorFlow: **Google** が開発・公開した深層学習フレームワーク。本番環境やモバイル展開（TensorFlow Lite）に強い。
- PyTorch: **Meta（Facebook）** が開発。Python 親和性が高く動的計算グラフのため**研究・実装しやすい**。現在の研究界の標準。
- Keras: TensorFlow に統合された高レベル API。シンプルなコードで NN を構築できる。
- JAX: Google 製、関数型でGPU/TPU向けの自動微分ライブラリ。

### 経験則・データ
- バーニーおじさんのルール（Uncle Bernie's rule）: 「ニューラルネットワークを正しく学習させるには、**パラメータ数の10倍の学習データ**が必要である」という経験則に基づくルールのこと。
- オーバーサンプリング: 不均衡データにおいて、データ数が少ないクラスのデータを複製・合成して数を増やす前処理。
- ダウンサンプリング: （アンダーサンプリングともいう）不均衡データにおいて、データ数が多いクラスのデータをランダムに削除して数を減らす前処理。
- 次元の呪い: データの次元（特徴量の数）が増えすぎると、必要なデータ量や計算量が爆発的に増加し、AIの性能が低下してしまう現象。
- 平滑化: 画像などにおけるノイズの除去処理。周囲のピクセルの平均値をとるなどして、画像をぼかして滑らかにする。
- 標準化: 全データの平均値を0、標準偏差を1になるように分布を整える操作。学習の効率化を図り、過学習を防ぐ前処理。
- 白色化: データ間の相関（被り）をなくし、さらに標準化を行うことで、学習の効率化を図る高度な前処理。
- 正規化: データを「0から1の間」など、一定の範囲内に収めるように変換する前処理。
- arXiv: 数理統計学、自然科学、電子工学、システム科学、経済学などの分野において、プレプリント（査読前論文）を含む様々な論文が保存・公開されているWebサイト。AIの最新技術はここでいち早く発表される。

### 【重要】モデル・アプローチ・手法の違いと使われ方の整理

モデル・アプローチ・手法の区別は用語理解の基本。以下のように整理しておくと把握しやすい。

**1. モデル（アーキテクチャ）＝ AIの「脳の構造設計図」**
* **RNN, LSTM, GRU:** （音声認識、機械翻訳AIなどに利用）文章などの時系列データを扱う構造。
* **CNN, ResNet, AlexNet:** （顔認識、自動運転のカメラAIなどに利用）画像の特徴を抽出する構造。
* **オートエンコーダ:** （異常検知AIやノイズ除去などに利用）データを圧縮・復元する構造。

**2. 手法（アルゴリズム / 工夫）＝ 学習をうまく進めるための「テクニック」**
* **バッチ正規化, ドロップアウト, 早期終了:** 過学習を防いだり、学習を安定させるための工夫。
* **Adam, RMSprop:** 山の斜面を効率よく下る（勾配降下法）ための計算アルゴリズム。
* **Experience Replay, ノイジーネットワーク:** DQN（強化学習）をうまく学習させるためのテクニック。

**3. アプローチ ＝ AI開発における「大きな戦略・方針」**
* **転移学習 / ファインチューニング:** ゼロから学習するのではなく、既存の優秀なAIの知識をベースラインにして新しいAIを作る戦略。
* **ミニバッチ学習:** データを全部一気に計算するのではなく、小分けにして効率よく計算させる学習戦略。

# 3章のDL技術と現代の LLM / VLM をつなぐ

第3章で学ぶ古典的なDL技術は、**そのまま現代の生成AI（LLM/VLM）の土台**として使われている。基礎技術と最新トレンドを橋渡しするための整理。

## 1. 現代の生成AIの「学習の心臓部」として使われているもの

- **誤差逆伝播法（Backpropagation）**: 最新の超巨大LLMであっても、AIが賢くなるための**根本的な仕組み**はこれ。出力された文章の間違い（誤差）を後ろに伝播させてパラメータを調整する。
- **Adam / AdamW（最適化アルゴリズム）**: LLMの学習において、パラメータを更新するアルゴリズムは現在も **Adam** またはその派生形（**AdamW** など）がほぼ標準（デファクトスタンダード）として使われている。
- **ソフトマックス関数**: LLM が「次にどの単語（**トークン**）を出力するか」を確率で決める際、出力層の最後の計算には必ずこのソフトマックス関数が使われている。
- **GPGPU / GPU**: LLMやVLMの膨大な並列計算は、**NVIDIA 製の超高性能 GPU**（H100、B100 など）が**数千〜数万個単位**で連携して処理している。

## 2. 現代の生成AIの「開発プロセス」そのもの

- **転移学習 / ファインチューニング**: LLMの作り方は、まさにこれの**究極系**。
    - **事前学習（Pre-training）**: インターネット上の全データで基礎知識を身につけさせる（転移学習のベース）。
    - **ファインチューニング（指示チューニング, SFT）**: 人間の指示通りに答えるように調整。
    - **RLHF（人間フィードバックによる強化学習）**: さらに人間の選好に合わせて調整 → ChatGPT のような対話AI が完成。
    - 詳細は [9-生成AI・基盤モデル特集](9-生成AI・基盤モデル特集.md) 参照。

## 3. LLMを「軽く・安く・速く」するための必須技術

現在のAI業界で最もホットな領域の一つが、第3章の最後に出てきた **「モデルの軽量化技術」**。

- **量子化（Quantization）**: 本来なら巨大なサーバーでしか動かない LLM を、個人のパソコンやスマートフォンで動かせるようにするために、パラメータの精度を落とす（**8bit / 4bit への圧縮**）処理が毎日のように研究・活用されている。
- **蒸留（Knowledge Distillation）**: 巨大で賢い LLM（例：GPT-4 クラス）の回答を**教師データ**として、小さい LLM（生徒）に学習させ、**スマホで動くような軽量かつ高性能なモデル**を作る手法として大活躍。
- **LoRA / PEFT**: ファインチューニング時に**全パラメータを更新せず**、低ランクの差分のみ学習することで省メモリ化する手法（詳細は9章）。

## 4. VLM（視覚＋言語モデル）における画像処理

- **CNN / ResNet 的なアプローチ**: 画像を入力できる VLM において、画像を AI が理解できる数値（特徴量）に変換する役割（**ビジョンエンコーダ**）として、CNN ベースの技術やその発展形が使われている。
- **Vision Transformer（ViT）**: 近年は CNN ではなく Transformer ベースの ViT がビジョンエンコーダの主流に（GPT-4V、Gemini など）。
- **CLIP**（OpenAI, 2021）: 画像とテキストを**対照学習**で同じ埋め込み空間に揃えたモデル。多くの VLM の土台。

## 💡 補足：RNN/LSTM から Transformer への進化

第3章では自然言語（テキスト）の処理として **RNN / LSTM** を学ぶが、**実は現在のLLMはRNNやLSTMをほとんど使っていない**。

現在のLLMは、RNN の欠点（計算を**直列で行うため遅い**、**長すぎる文章を忘れる**）を克服するために、**2017年に Google が発表した「Transformer」**というアーキテクチャ（と、そこに含まれる **Attention 機構**）でできている。

[4-ディープラーニングの研究分野](4-ディープラーニングの研究分野.md) と [9-生成AI・基盤モデル特集](9-生成AI・基盤モデル特集.md) では、以下の進化の流れを扱う：

```
RNN  →  LSTM  →  seq2seq + Attention  →  Transformer  →  BERT / GPT  →  LLM の誕生
```

詳細は [4-ディープラーニングの研究分野](4-ディープラーニングの研究分野.md) と [9-生成AI・基盤モデル特集](9-生成AI・基盤モデル特集.md) で扱う。
