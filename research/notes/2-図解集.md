## 2-1 機械学習の主要分野の基本

#### 機械学習の分類

```mermaid
graph TD
    ML[機械学習]
    ML --> SL[教師あり学習<br/>Supervised Learning]
    ML --> UL[教師なし学習<br/>Unsupervised Learning]
    ML --> SSL[半教師あり学習<br/>Semi-Supervised]
    ML --> Self[自己教師あり学習<br/>Self-Supervised]
    ML --> RL[強化学習<br/>Reinforcement Learning]

    SL --> Cls[分類<br/>Classification<br/>カテゴリ予測]
    SL --> Reg[回帰<br/>Regression<br/>数値予測]

    UL --> Clu[クラスタリング<br/>K-Means / 階層型 / DBSCAN]
    UL --> Dim[次元削減<br/>PCA / t-SNE / UMAP]
    UL --> Ano[異常検知]

    RL --> Pol[方策ベース<br/>Policy Gradient]

    style SL fill:#cfe
    style UL fill:#fec
    style RL fill:#fce
    style Self fill:#cef
```

#### 強化学習の基本ループ

```mermaid
graph LR
    Agent[エージェント<br/>Agent]
    Env[環境<br/>Environment]

    Agent -->|行動 a| Env
    Env -->|状態 s, 報酬 r| Agent

    style Env fill:#fce
```

> **目的:** 累積報酬 Σγᵗ·rₜ を最大化する方策 π を学習。

## 2-2 過学習と汎化性能

#### 過学習・未学習・適合のイメージ

```mermaid
graph LR
    UF[未学習<br/>Underfitting]
    Fit[適合<br/>Good Fit]
    OF[過学習<br/>Overfitting]

    UF -->|モデル複雑度を上げる| Fit
    Fit -->|モデル複雑度を上げ過ぎる| OF

    UF -. 特徴 .-> UF1[訓練・検証<br/>両方で誤差大]
    Fit -. 特徴 .-> Fit1[訓練・検証<br/>両方で誤差小]
    OF -. 特徴 .-> OF1[訓練誤差小<br/>検証誤差大]

    style UF fill:#fcc
    style Fit fill:#cfe
    style OF fill:#fce
```

#### バイアス-バリアンスのトレードオフ

```mermaid
graph TD
    Total[汎化誤差<br/>Total Error]
    Total --> Bias[バイアス²<br/>Bias²]
    Total --> Var[バリアンス<br/>Variance]
    Total --> Noise[既約誤差<br/>Irreducible Error]

    Bias -. 高いと .-> Simple[モデルが単純<br/>→ 未学習]
    Var -. 高いと .-> Complex[モデルが複雑<br/>→ 過学習]

    style Bias fill:#fcc
    style Var fill:#fce
    style Noise fill:#eee
```

> 汎化誤差 ≈ バイアス² + バリアンス + 既約誤差

#### 正則化手法の比較

```mermaid
graph TD
    Reg[正則化<br/>Regularization]
    Reg --> L1[L1正則化<br/>Lasso]
    Reg --> L2[L2正則化<br/>Ridge]
    Reg --> EN[Elastic Net]
    Reg --> ES[早期終了<br/>Early Stopping]

    L1 -. ペナルティ .-> L1P[Σ|w|<br/>絶対値の和]
    L2 -. ペナルティ .-> L2P[Σw²<br/>二乗の和]
    EN -. ペナルティ .-> ENP[L1 + L2 の組合せ]

    L1 -. 効果 .-> L1E[疎な解<br/>特徴量選択]
    L2 -. 効果 .-> L2E[小さく滑らか<br/>過学習抑制]

    style L1 fill:#fce
    style L2 fill:#cfe
    style EN fill:#fec
```

## 2-3 機械学習の具体的な手法

#### 決定木の例

```mermaid
graph TD
    Root{年齢 ≧ 30 ?}
    Root -->|Yes| N1{年収 ≧ 500万 ?}
    Root -->|No| L3[購入しない]
    N1 -->|Yes| L1[購入する]
    N1 -->|No| L2[購入しない]

    style Root fill:#cfe
    style L1 fill:#cfe
    style L2 fill:#fcc
    style L3 fill:#fcc
```

> 各内部ノードは条件分岐、葉ノードがクラス／予測値。**ジニ不純度・情報利得**で分割を選ぶ。

#### アンサンブル学習の3方式

```mermaid
graph TD
    Ens[アンサンブル学習]
    Ens --> Bag[バギング<br/>Bagging]
    Ens --> Boo[ブースティング<br/>Boosting]
    Ens --> Sta[スタッキング<br/>Stacking]

    Bag -. 構造 .-> BagS[並列<br/>独立学習]
    Boo -. 構造 .-> BooS[直列<br/>前の誤りを次が補正]
    Sta -. 構造 .-> StaS[多段<br/>メタモデルで統合]

    Bag -. 代表 .-> BagR[ランダムフォレスト]
    Boo -. 代表 .-> BooR[AdaBoost / XGBoost / LightGBM]

    style Bag fill:#cfe
    style Boo fill:#fce
    style Sta fill:#fec
```

## 2-4 精度評価とハイパーパラメータの最適化

#### 混同行列の構造

```mermaid
graph TD

        FP[FP<br/>偽陽性<br/>負例を正例と誤予測]
        FN[FN<br/>偽陰性<br/>正例を負例と誤予測]
        TN[TN<br/>真陰性<br/>負例を負例と予測]
    end

    style TP fill:#cfe
    style TN fill:#cfe

    style FN fill:#fcc
```

#### 適合率・再現率・特異度の関係

```mermaid
graph LR
    Acc[正解率<br/>Accuracy<br/>TP+TN / 全体]

    Pre[適合率<br/>Precision<br/>TP / TP+FP]
    Rec[再現率<br/>Recall・感度<br/>TP / TP+FN]
    Spe[特異度<br/>Specificity<br/>TN / TN+FP]
    F1[F1スコア<br/>適合率と再現率の<br/>調和平均]

    Pre -. トレードオフ .-> Rec
    Pre --> F1
    Rec --> F1

    Pre -. 重視シーン .-> PreS[誤検出を減らしたい<br/>例: スパム判定]

    style Pre fill:#cfe

    style F1 fill:#cef
```

#### ROC曲線・AUCの考え方


## 2-5 データ加工

#### データ前処理パイプライン

```mermaid
graph LR
    Raw[生データ]
    Raw --> Clean[欠損値・外れ値処理]
    Clean --> Enc[カテゴリ変数の<br/>エンコーディング]
    Enc --> Scale[スケーリング<br/>標準化 / 正規化]
    Scale --> FE[特徴量エンジニアリング]
    FE --> Imb[不均衡データ対策<br/>必要に応じて]
    Imb --> Train[学習用データ]

    style Raw fill:#fce
    style Train fill:#cfe
```

#### 標準化 vs 正規化

```mermaid
graph TD
    Scale[スケーリング]
    Scale --> Std[標準化<br/>Standardization]
    Scale --> Norm[正規化<br/>Min-Max]
    Scale --> White[白色化<br/>Whitening]

    Std -. 式 .-> StdF[「x - μ」/ σ]
    Std -. 結果 .-> StdR[平均0・分散1]

    Norm -. 式 .-> NormF[「x - min」/「max - min」]
    Norm -. 結果 .-> NormR[範囲 0〜1]

    White -. 結果 .-> WhiteR[標準化 + 無相関化]

    style Std fill:#cfe
    style Norm fill:#fce
    style White fill:#fec
```

#### カテゴリ変数のエンコーディング比較

```mermaid
graph TD
    Cat[カテゴリ変数]
    Cat --> Order{順序がある?}
    Order -->|Yes<br/>例: 小・中・大| Label[ラベルエンコーディング<br/>0, 1, 2 に変換]
    Order -->|No<br/>例: 赤・青・緑| OneHot[One-Hotエンコーディング<br/>列ごとに 0/1]

    Label -. 注意 .-> LabelW[順序のないカテゴリに<br/>使うと誤った大小関係を学習]

    style Label fill:#fec
    style OneHot fill:#cfe
    style LabelW fill:#fcc
```

#### 不均衡データ対策

```mermaid
graph TD
    Imb[不均衡データ<br/>例: 1% vs 99%]
    Imb --> Under[アンダーサンプリング<br/>多数派を削る]
    Imb --> Over[オーバーサンプリング<br/>少数派を増やす]
    Imb --> Eval[評価指標を変更<br/>F1 / PR-AUC]

    Over --> Dup[単純複製]
    Over --> SMOTE[SMOTE<br/>近傍データから<br/>合成生成]

    Under -. デメリット .-> UnderD[情報が失われる]
    Dup -. デメリット .-> DupD[過学習しやすい]

    style SMOTE fill:#cfe
    style Eval fill:#fec
```
