## 学習パラダイム

### 教師あり / 教師なし / 半教師あり / 自己教師あり / 強化学習

| 学習方式 | データ | 目的 | 例 |
|---|---|---|---|
| **教師あり学習** | 入力 + 正解ラベル | 入出力の写像を学習 | 分類・回帰 |
| **教師なし学習** | 入力のみ | データ構造の抽出 | クラスタリング、次元削減 |
| **半教師あり学習** | 一部ラベル付き + 大量ラベルなし | 少量ラベルで高性能 | 実務での主流 |
| **自己教師あり学習（SSL）** | ラベルなし、データ自身から擬似ラベル生成 | 表現学習 | BERT（MLM）、CLIP |
| **強化学習** | 状態・行動・報酬 | 累積報酬最大化 | ゲームAI、ロボット |
| **転移学習** | 事前学習済みモデル + 少量データ | 別タスクへ転用 | 画像認識FT |
| **マルチタスク学習** | 複数タスクのラベル | 同時学習で汎化向上 | – |
| **メタ学習** | タスクの分布 | 「学び方」を学ぶ | Few-shot 学習 |

## 評価指標：分類

混同行列：TP（真陽性）/ TN（真陰性）/ FP（偽陽性）/ FN（偽陰性）

| 指標 | 式 | 何を見るか |
|---|---|---|
| **正解率（Accuracy）** | (TP+TN) / 全体 | 全体的に当たっているか。**不均衡データに弱い** |
| **適合率（Precision）** | TP / (TP+FP) | 「陽性と予測したうち本当に陽性」。**FPを減らしたい時** |
| **再現率（Recall, 感度）** | TP / (TP+FN) | 「実際の陽性のうち見つけた割合」。**FNを減らしたい時** |
| **F1 スコア** | Precision と Recall の**調和平均** | バランス |
| **特異度（Specificity）** | TN / (TN+FP) | 「実際の陰性のうち正しく陰性と判定」 |
| **ROC曲線** | FPR vs TPR | 閾値による性能変化 |
| **AUC** | ROC曲線下面積 | 0.5=ランダム, 1=完全 |
| **PR曲線** | Precision vs Recall | **不均衡データに有効** |

**用途別の優先指標**
- 病気診断・スパム検知（見逃し致命的）→ **再現率重視**
- 推薦システム・誤検知が痛い→ **適合率重視**

## 過学習 / 未学習 / バイアス・バリアンス

| 用語 | 意味 | 対策 |
|---|---|---|
| **過学習（Overfitting）** | 訓練データに適合しすぎ汎化しない | 正則化、Dropout、データ増強、早期終了 |
| **未学習（Underfitting）** | モデルが単純すぎ訓練データすら捉えられない | モデル拡張、特徴量追加 |
| **バイアス（Bias）** | モデルの仮定の単純さによる誤差 | 高い→未学習傾向 |
| **バリアンス（Variance）** | データのゆらぎへの感度 | 高い→過学習傾向 |
| **バイアス-バリアンスのトレードオフ** | 両者は逆相関、最適点を探す | – |

## 正則化

| 手法 | 概要 | 特徴 |
|---|---|---|
| **L1 正則化（Lasso）** | 重みの絶対値和をペナルティ | **疎（ゼロが多い）** な解 → 特徴選択 |
| **L2 正則化（Ridge）** | 重みの二乗和をペナルティ | 重みを**小さく**するが0にはしにくい |
| **Elastic Net** | L1 + L2 | 両方の利点 |
| **Dropout** | 学習時に一部ノードをランダムに無効化 | アンサンブル効果 |
| **Early Stopping** | 検証誤差が悪化したら停止 | – |
| **データ拡張（Augmentation）** | 入力を変形して増やす | – |

## 勾配降下法のバリエーション

| 手法 | 1更新で使うサンプル | 特徴 |
|---|---|---|
| **バッチ勾配降下** | 全データ | 安定だが遅い、メモリ大 |
| **確率的勾配降下（SGD）** | 1サンプル | 速いがノイジー |
| **ミニバッチ勾配降下** | 数十〜数百 | **実務の主流** |

最適化アルゴリズム：

| 手法 | 特徴 |
|---|---|
| **モメンタム** | 過去の勾配を慣性として加える |
| **AdaGrad** | パラメータごとに学習率を調整、ただし学習率が単調減少 |
| **RMSProp** | AdaGrad の減衰問題を改善 |
| **Adam** | モメンタム + RMSProp の良いとこどり、**実務の標準** |
| **AdamW** | Adam + 重み減衰の正しい実装 |

## 活性化関数

| 関数 | 出力範囲 | 特徴 |
|---|---|---|
| **シグモイド** | (0, 1) | 勾配消失しやすい、二値分類の出力 |
| **tanh** | (-1, 1) | シグモイドより中心化 |
| **ReLU** | [0, ∞) | 勾配消失しにくい、**標準**。死んだReLU問題 |
| **Leaky ReLU** | 全実数 | 負側にもわずかに勾配 |
| **ELU / GELU / Swish** | 改良型 | Transformerでは GELU が多い |
| **ソフトマックス** | (0,1)で総和1 | 多クラス分類の出力層 |

## 物体検出系の用語

| 用語 | 概要 |
|---|---|
| **画像分類** | 画像全体に1ラベル |
| **物体検出** | 矩形（バウンディングボックス）+ クラス |
| **セマンティックセグメンテーション** | ピクセル単位でクラス分類（個体は区別しない） |
| **インスタンスセグメンテーション** | ピクセル単位 + **個体を区別** |
| **パノプティックセグメンテーション** | セマンティック + インスタンスの統合 |

物体検出の方式：

| 方式 | 特徴 | 代表 |
|---|---|---|
| **2段階（Two-stage）** | 領域提案 → 分類。精度高、遅い | R-CNN, Fast R-CNN, Faster R-CNN |
| **1段階（One-stage）** | 一気に検出。速い | YOLO, SSD, RetinaNet |
| **Transformerベース** | 集合予測 | DETR |

## 次元削減

| 手法 | 線形/非線形 | 用途 |
|---|---|---|
| **PCA** | 線形 | 分散最大の軸を抽出 |
| **ICA** | 線形 | 独立な成分に分解（信号分離） |
| **LDA**（線形判別分析） | 線形 | クラス分離最大化（**教師あり**） |
| **t-SNE** | 非線形 | 可視化用、距離関係保存 |
| **UMAP** | 非線形 | t-SNE より高速、構造保持 |

※ **LDA は2つある**：Linear Discriminant Analysis（次元削減）と Latent Dirichlet Allocation（トピックモデル）

## 確率分布・統計

| 用語 | 概要 |
|---|---|
| **頻度主義 vs ベイズ主義** | 確率を「頻度」と見るか「信念の度合い」と見るか |
| **MLE（最尤推定）** | 尤度最大化、頻度主義 |
| **MAP 推定** | 事後確率最大化、ベイズ主義（事前分布あり） |
| **ベイズ推定** | 事後分布全体を扱う |
| **KL ダイバージェンス** | 分布間距離（**非対称**） |
| **JS ダイバージェンス** | 対称化したKL |
| **交差エントロピー** | 分類タスクの標準損失 |
