【概要】
探索木とは、問題の解決策を見つけるために、取り得るすべての状態や選択肢を
木の枝分かれ（ツリー構造）のように図式化し、正解への経路を探し出す手法です。
AIの初期（第1次AIブーム）における「推論・探索」の代表的なアプローチであり、
迷路の攻略やパズル（トイ・プロブレム）を解く際によく用いられます。

探索を進めるアルゴリズムには、大きく分けて以下の2つのアプローチがあります。

------------------------------------------------------------------------------
1. 深さ優先探索（DFS: Depth-First Search）
------------------------------------------------------------------------------
【仕組み】
スタート地点からある枝（選択肢）を選んだら、行き止まりになるまでひたすら深く
掘り進めます。行き止まりに到達したら、一つ前の分岐点まで戻り（バックトラック）、
まだ探索していない別の枝を探索します。これをゴールが見つかるまで繰り返します。

【特徴と実装のポイント】
- メリット: 現在探索している経路の情報だけを記憶すればよいため、メモリ消費が少ない。
- デメリット: ゴールは見つけられるが、それが「最短経路」である保証はない。
- 実装時のデータ構造: 「スタック（Stack：後入れ先出し）」を使う。
  （※Pythonでは通常のリストの append() と pop() で簡単に実装可能）

------------------------------------------------------------------------------
2. 幅優先探索（BFS: Breadth-First Search）
------------------------------------------------------------------------------
【仕組み】
スタート地点から近い深さ（階層）にあるノード（選択肢）を、横一列にすべて順番に
調べていきます。現在の階層をすべて調べ終わってから、次の深い階層へと進みます。
水面に石を投げた時の「波紋」が広がっていくようなイメージで探索を進めます。

【特徴と実装のポイント】
- メリット: ゴールが存在する場合、必ず「最短経路」を最初に見つけ出すことができる。
- デメリット: 各階層のすべての分岐を記憶しながら進むため、階層が深くなったり
  選択肢が多いと、メモリの消費量が爆発的に増える。
- 実装時のデータ構造: 「キュー（Queue：先入れ先出し）」を使う。
  （※Pythonでは collectionsモジュールの deque を使うのが一般的）

==============================================================================
"""
